# 漏 Leak, vulnerability

- **Character**: 漏
- **Pinyin**: lòu
- **Meaning**: leak, vulnerability
- **Radical**: 氵 (water)
- **Stroke count**: 14

## Compounds

- 漏洞 (lòu dòng) — vulnerability, loophole
- 泄漏 (xiè lòu) — leak

## Example Sentences

- 发现安全漏洞。(Fā xiàn ān quán lòu dòng.) — A security vulnerability was found.
