# 键 Key

- **Character**: 键
- **Pinyin**: jiàn
- **Meaning**: key, crucial
- **Radical**: 金 (metal)
- **Stroke count**: 13

## Compounds

- 键盘 (jiàn pán) — keyboard
- 关键 (guān jiàn) — key, crucial

## Example Sentences

- 这是关键问题。(Zhè shì guān jiàn wèn tí.) — This is the key issue.

## Notes

键 with metal radical suggests a lock mechanism, now essential for keyboard and key concepts.
