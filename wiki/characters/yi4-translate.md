# 译 Translate, interpret

- **Character**: 译
- **Pinyin**: yì
- **Meaning**: translate, interpret
- **Radical**: 讠 (speech)
- **Stroke count**: 7

## Compounds

- 编译 (biān yì) — compile
- 翻译 (fān yì) — translate

## Example Sentences

- 编译器把代码译成机器语言。(Biān yì qì bǎ dài mǎ yì chéng jī qì yǔ yán.) — The compiler translates code into machine language.

## Notes

Used in 编译 (compile), 编译器 (compiler), translation from source to machine code
