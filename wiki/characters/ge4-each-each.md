# 各 Each

- **Character**: 各
- **Pinyin**: gè
- **Meaning**: each, every, various
- **Radical**: 口 (mouth)
- **Stroke count**: 6

## Compounds

- 各种 (gè zhǒng) — various kinds
- 各地 (gè dì) — various places

## Example Sentences

- 各位同学好！(Gè wèi tóng xué hǎo!) — Hello, everyone!

## Notes

各 means each/every. 各位 is a formal 'everyone.' 各自 = each (person) respectively.
