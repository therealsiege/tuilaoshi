# 创 Create, start

- **Character**: 创
- **Pinyin**: chuàng
- **Meaning**: create, start
- **Radical**: 刀 (knife)
- **Stroke count**: 6

## Compounds

- 创造 (chuàngzào) — create
- 创新 (chuàngxīn) — innovate

## Example Sentences

- 他创造了新纪录。(Tā chuàngzào le xīn jìlù.) — He created a new record.

## Notes

Common character for creation and innovation.
