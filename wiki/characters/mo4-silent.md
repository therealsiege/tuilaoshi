# 默 Silent, write from memory

- **Character**: 默
- **Pinyin**: mò
- **Meaning**: silent, write from memory
- **Radical**: 黑 (black)
- **Stroke count**: 16

## Compounds

- 沉默 (chénmò) — silent, taciturn
- 默认 (mòrèn) — default, acquiesce

## Example Sentences

- 他沉默不语。(Tā chénmò bù yǔ.) — He remains silent.

## Notes

Common character for silence or doing things from memory.
