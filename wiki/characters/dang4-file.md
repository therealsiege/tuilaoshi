# 档 File

- **Character**: 档
- **Pinyin**: dàng
- **Meaning**: file, grade,档
- **Radical**: 木 (tree)
- **Stroke count**: 10

## Compounds

- 文档 (wén dàng) — document, file
- 档案 (dàng àn) — 档 file, record

## Example Sentences

- 请保存文档。(Qǐng bǎo cún wén dàng.) — Please save the document.

## Notes

档 originally referred to shelves for storing items, now essential for digital files and documents.
