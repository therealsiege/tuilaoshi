# 复 Duplicate, repeat

- **Character**: 复
- **Pinyin**: fù
- **Meaning**: duplicate, repeat
- **Radical**: 夂 (walk slowly)
- **Stroke count**: 9

## Compounds

- 复制 (fù zhì) — copy, duplicate
- 恢复 (huī fù) — restore, recover

## Example Sentences

- 请复制这段文字。(Qǐng fù zhì zhè duàn wén zì.) — Please copy this text.

## Notes

Used in 复制 (copy), 恢复 (restore), 重复 (repeat), fundamental file operations
