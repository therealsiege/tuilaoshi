# 档 档案, grade, file

- **Character**: 档
- **Pinyin**: dàng
- **Meaning**: 档案, grade, file
- **Radical**: 木 (wood)
- **Stroke count**: 10

## Compounds

- 档案 (dàng àn) — 档案, records
- 文档 (wén dàng) — document, file

## Example Sentences

- 人事部保管员工档案。(Rén shì bù bǎo guǎn yuán gōng dàng àn.) — HR keeps employee records.

## Notes

档案管理 is records management. 高档 means high-grade.
