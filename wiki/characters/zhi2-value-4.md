# 值 Value

- **Character**: 值
- **Pinyin**: zhí
- **Meaning**: value
- **Radical**: 亻 (person)
- **Stroke count**: 10

## Compounds

- 数值 (shù zhí) — numerical value
- 价值 (jià zhí) — value

## Example Sentences

- 这个值不正确。(Zhè gè zhí bù zhèng què.) — This value is incorrect.
