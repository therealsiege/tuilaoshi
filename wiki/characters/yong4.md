# 用 — Use

- **Character**: 用
- **Pinyin**: yòng
- **Meaning**: to use, to employ; use, utility
- **Radical**: 用 (use — itself a radical)
- **Stroke count**: 5

## Compounds

- 用处 (yòngchù) — use, usefulness
- 有用 (yǒuyòng) — useful
- 没用 (méiyòng) — useless
- 使用 (shǐyòng) — to use, to employ (formal)
- 不用 (bùyòng) — need not, don't bother
- 用功 (yònggōng) — hardworking, studious

## Example Sentences

- 你会用筷子吗？(Nǐ huì yòng kuàizi ma?) — Can you use chopsticks?
- 不用谢。(Bùyòng xiè.) — You're welcome. (Literally: No need to thank.)
- 这本书对学中文很有用。(Zhè běn shū duì xué Zhōngwén hěn yǒuyòng.) — This book is very useful for studying Chinese.

## Notes

用 is both a standalone character and a radical. It originally depicted a bucket or vessel, something put to practical use. The character is one of the most common in Chinese and appears in many everyday expressions. 不用 (bùyòng) meaning "no need to" is a polite and casual way to decline or reassure, heard constantly in daily conversation.
