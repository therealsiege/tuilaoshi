# 页 Page

- **Character**: 页
- **Pinyin**: yè
- **Meaning**: page
- **Radical**: 页 (page)
- **Stroke count**: 6

## Compounds

- 网页 (wǎng yè) — web page
- 页面 (yè miàn) — page

## Example Sentences

- 这个网页加载很慢。(Zhè gè wǎng yè jiā zài hěn màn.) — This web page loads slowly.

## Notes

Used in 网页 (web page), 页面 (page), 主页 (homepage)
