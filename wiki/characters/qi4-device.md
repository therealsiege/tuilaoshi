# 器 Device, instrument, utensil

- **Character**: 器
- **Pinyin**: qì
- **Meaning**: device, instrument, utensil
- **Radical**: 口 (mouth)
- **Stroke count**: 16

## Compounds

- 机器 (jī qì) — machine, machinery
- 仪器 (yí qì) — instrument

## Example Sentences

- 这台机器运转正常。(Zhè tái jī qì yùn zhuǎn zhèng cháng.) — This machine is operating normally.
