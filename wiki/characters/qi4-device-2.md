# 器 Device, instrument

- **Character**: 器
- **Pinyin**: qì
- **Meaning**: device, instrument
- **Radical**: 口 (mouth)
- **Stroke count**: 16

## Compounds

- 服务器 (fú wù qì) — server
- 浏览器 (liú lǎn qì) — browser

## Example Sentences

- 请更新浏览器。(Qǐng gēng xīn liú lǎn qì.) — Please update the browser.

## Notes

Used in 服务器 (server), 浏览器 (browser), 容器 (container)
