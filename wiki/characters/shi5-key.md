# 匙 Key, spoon

- **Character**: 匙
- **Pinyin**: shi
- **Meaning**: key, spoon
- **Radical**: 匕 (spoon)
- **Stroke count**: 11

## Compounds

- 钥匙 (yào shi) — key
- 汤匙 (tāng chí) — spoon

## Example Sentences

- 私钥不能泄露。(Sī yào bù néng xiè lòu.) — Private keys must not be leaked.

## Notes

Used in 钥匙 (key), security and encryption
