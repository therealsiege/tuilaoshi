# 云 Cloud

- **Character**: 云
- **Pinyin**: yún
- **Meaning**: cloud
- **Radical**: 二 (two)
- **Stroke count**: 4

## Compounds

- 白云 (bái yún) — white cloud
- 云锣 (yún luó) — cloud gongs

## Example Sentences

- 云锣是一组小锣。(Yún luó shì yī zǔ xiǎo luó.) — Cloud gongs are a set of small gongs.

## Notes

云 means cloud; 云锣 are tuned gongs arranged in a frame.
