# 槽 Slot, groove

- **Character**: 槽
- **Pinyin**: cáo
- **Meaning**: slot, groove
- **Radical**: 木 (wood)
- **Stroke count**: 15

## Compounds

- 插槽 (chā cáo) — slot
- 内存槽 (nèi cún cáo) — memory slot

## Example Sentences

- 主板上有四个内存槽。(Zhǔ bǎn shàng yǒu sì gè nèi cún cáo.) — There are four memory slots on the motherboard.

## Notes

Used in 插槽 (slot), 扩展槽 (expansion slot), hardware terminology
