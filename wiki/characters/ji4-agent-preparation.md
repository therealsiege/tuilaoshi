# 剂 Agent

- **Character**: 剂
- **Pinyin**: jì
- **Meaning**: preparation, dose, agent
- **Radical**: 刂(knife)
- **Stroke count**: 8

## Compounds

- 清洁剂 (qīng jié jì) — detergent
- 试剂 (shì jì) — reagent

## Example Sentences

- 用清洁剂洗碗。(Yòng qīng jié jì xǐ wǎn.) — Wash dishes with detergent.

## Notes

剂 simplified from 劑. Knife 刂 cutting precise amounts, prepared substance.
