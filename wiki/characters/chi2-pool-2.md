# 池 Pool

- **Character**: 池
- **Pinyin**: chí
- **Meaning**: pool
- **Radical**: 氵 (water)
- **Stroke count**: 6

## Compounds

- 连接池 (lián jiē chí) — connection pool
- 内存池 (nèi cún chí) — memory pool

## Example Sentences

- 线程池可以提高性能。(Xiàn chéng chí kě yǐ tí gāo xìng néng.) — Thread pools can improve performance.

## Notes

Used in 连接池 (connection pool), 线程池 (thread pool), 电池 (battery)
