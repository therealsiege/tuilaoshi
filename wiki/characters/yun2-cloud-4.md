# 云 Cloud

- **Character**: 云
- **Pinyin**: yún
- **Meaning**: cloud
- **Radical**: 二 (two)
- **Stroke count**: 4

## Compounds

- 云计算 (yún jì suàn) — cloud computing
- 云端 (yún duān) — cloud (storage)

## Example Sentences

- 数据存储在云端。(Shù jù cún chǔ zài yún duān.) — Data is stored in the cloud.

## Notes

Used in 云计算 (cloud computing), 云存储 (cloud storage), 云服务 (cloud service)
