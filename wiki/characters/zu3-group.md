# 组 Group, organize, set

- **Character**: 组
- **Pinyin**: zǔ
- **Meaning**: group, organize, set
- **Radical**: 纟 (silk)
- **Stroke count**: 8

## Compounds

- 组合 (zǔ hé) — combination, compose
- 小组 (xiǎo zǔ) — group, team

## Example Sentences

- 这些元素可以有多种组合。(Zhè xiē yuán sù kě yǐ yǒu duō zhǒng zǔ hé.) — These elements can have multiple combinations.
