# 栈 Stack

- **Character**: 栈
- **Pinyin**: zhàn
- **Meaning**: stack
- **Radical**: 木 (wood)
- **Stroke count**: 9

## Compounds

- 堆栈 (duī zhàn) — stack (data structure)
- 栈溢出 (zhàn yì chū) — stack overflow

## Example Sentences

- 栈是一种后进先出的数据结构。(Zhàn shì yī zhǒng hòu jìn xiān chū de shù jù jié gòu.) — A stack is a last-in-first-out data structure.

## Notes

Data structure term, used in 堆栈 (stack), 全栈 (full-stack)
