# 搁 Put, Place, 搁置 Shelve

- **Character**: 搁
- **Pinyin**: gē
- **Meaning**: put, place, 搁置 shelve
- **Radical**: 扌(hand)
- **Stroke count**: 12

## Compounds

- 搁置 (gē zhì) — shelve, put aside
- 搁浅 (gē qiǎn) — run aground, be stranded
- 耽搁 (dān gē) — delay

## Example Sentences

- 这个计划暂时搁置了。(Zhège jìhuà zànshí gēzhì le.) — This plan has been temporarily shelved.

## Notes

Verb for placing or shelving things. 搁置 means set aside/shelve (often projects or disputes). 搁浅 literally means run aground.
