# 镶 Inlay

- **Character**: 镶
- **Pinyin**: xiāng
- **Meaning**: inlay, set
- **Radical**: 钅(metal)
- **Stroke count**: 16

## Compounds

- 镶嵌 (xiāng qiàn) — inlay, set
- 镶边 (xiāng biān) — edge, border

## Example Sentences

- 这把宝剑镶嵌着宝石。(Zhè bǎ bǎojiàn xiāngqiàn zhe bǎoshí.) — This sword is inlaid with gems.

## Notes

镶 means to inlay or set precious materials into something. Common in jewelry and decorative arts.
