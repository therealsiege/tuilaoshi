# 流 Flow, stream

- **Character**: 流
- **Pinyin**: liú
- **Meaning**: flow, stream
- **Radical**: 氵 (water)
- **Stroke count**: 10

## Compounds

- 流量 (liú liàng) — traffic, data flow
- 数据流 (shù jù liú) — data stream

## Example Sentences

- 网站流量很大。(Wǎng zhàn liú liàng hěn dà.) — The website traffic is very high.

## Notes

Used in 流量 (traffic), 数据流 (data stream), 工作流 (workflow)
