# 函 Function

- **Character**: 函
- **Pinyin**: hán
- **Meaning**: function
- **Radical**: 凵 (container)
- **Stroke count**: 8

## Compounds

- 函数 (hán shù) — function
- 信函 (xìn hán) — letter

## Example Sentences

- 这是一个激活函数。(Zhè shì yī gè jī huó hán shù.) — This is an activation function.

Used in 函数 (function), 损失函数 (loss function), programming terminology
