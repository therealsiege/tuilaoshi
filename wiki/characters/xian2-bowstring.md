# 弦 Bowstring, chord, string

- **Character**: 弦
- **Pinyin**: xián
- **Meaning**: bowstring, chord, string
- **Radical**: 弓 (bow)
- **Stroke count**: 8

## Compounds

- 弦线 (xián xiàn) — chord
- 琴弦 (qín xián) — string (of instrument)

## Example Sentences

- 弦是连接圆上两点的线段。(Xián shì lián jiē yuán shàng liǎng diǎn de xiàn duàn.) — A chord is a line segment connecting two points on a circle.

## Notes

Line across circle or curve
