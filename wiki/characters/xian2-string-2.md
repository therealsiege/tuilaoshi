# 弦 String

- **Character**: 弦
- **Pinyin**: xián
- **Meaning**: string (of instrument), chord
- **Radical**: 弓(bow)
- **Stroke count**: 8

## Compounds

- 琴弦 (qín xián) — strings of a musical instrument
- 弦乐 (xián yuè) — string music

## Example Sentences

- 小提琴的弦断了。(Xiǎotíqín de xián duàn le.) — The violin string broke.

## Notes

弦 refers to strings on musical instruments or bowstrings. The bow radical 弓 reflects this connection.
