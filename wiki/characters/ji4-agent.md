# 剂 Agent

- **Character**: 剂
- **Pinyin**: jì
- **Meaning**: agent, dose
- **Radical**: 刂(knife)
- **Stroke count**: 8

## Compounds

- 洗涤剂 (xǐ dí jì) — detergent
- 粘合剂 (zhān hé jì) — adhesive

## Example Sentences

- 使用清洁剂。(Shǐ yòng qīng jié jì.) — Use cleaning agent.

## Notes

剂 with knife radical suggests measured portions, standard suffix for chemical agents.
