# 弦 String

- **Character**: 弦
- **Pinyin**: xián
- **Meaning**: string, bowstring
- **Radical**: 弓 (bow)
- **Stroke count**: 8

## Compounds

- 琴弦 (qín xián) — instrument string
- 弦乐 (xián yuè) — string music

## Example Sentences

- 这根琴弦断了。(Zhè gēn qín xián duàn le.) — This string broke.

## Notes

弦 refers to strings on musical instruments or bowstrings.
