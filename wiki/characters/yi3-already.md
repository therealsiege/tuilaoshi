# 已 Already

- **Character**: 已
- **Pinyin**: yǐ
- **Meaning**: already
- **Radical**: 己 (self)
- **Stroke count**: 3

## Compounds

- 已经 (yǐ jīng) — already
- 已知 (yǐ zhī) — known

## Example Sentences

- 我已经吃了。(Wǒ yǐ jīng chī le.) — I have already eaten.

## Notes

已 is almost always used in 已经 (already). Similar to 己 (self) and 巳 (6th earthly branch) — note the stroke differences.
