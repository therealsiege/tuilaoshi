# 服 Serve, service

- **Character**: 服
- **Pinyin**: fú
- **Meaning**: serve, service
- **Radical**: 月 (moon)
- **Stroke count**: 8

## Compounds

- 服务 (fú wù) — service
- 服务器 (fú wù qì) — server

## Example Sentences

- 服务器出现故障。(Fú wù qì chū xiàn gù zhàng.) — The server has malfunctioned.

Used in 服务 (service), 服务器 (server), 服装 (clothing)
