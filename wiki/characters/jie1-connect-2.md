# 接 Connect, interface

- **Character**: 接
- **Pinyin**: jiē
- **Meaning**: connect, interface
- **Radical**: 扌 (hand)
- **Stroke count**: 11

## Compounds

- 连接 (lián jiē) — connect
- 接口 (jiē kǒu) — interface, port

## Example Sentences

- 请检查网络连接。(Qǐng jiǎn chá wǎng luò lián jiē.) — Please check the network connection.

## Notes

Used in 连接 (connect), 接口 (interface), 直接 (direct)
