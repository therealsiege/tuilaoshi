# 枝 Branch, twig

- **Character**: 枝
- **Pinyin**: zhī
- **Meaning**: branch, twig
- **Radical**: 木 (wood)
- **Stroke count**: 8

## Compounds

- 树枝 (shù zhī) — tree branch
- 枝条 (zhī tiáo) — branch, twig

## Example Sentences

- 鸟儿在树枝上筑巢。(Niǎo ér zài shù zhī shàng zhù cháo.) — Birds build nests on tree branches.
