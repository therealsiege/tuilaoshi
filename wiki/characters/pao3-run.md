# 跑 To Run

- **Character**: 跑
- **Pinyin**: pǎo
- **Meaning**: to run
- **Radical**: 足 (foot)
- **Stroke count**: 12

## Compounds

- 跑步 (pǎo bù) — to jog, to run
- 长跑 (cháng pǎo) — long-distance running

## Example Sentences

- 他跑得很快。(Tā pǎo de hěn kuài.) — He runs very fast.

## Notes

跑 uses foot radical 足. 跑步 specifically means running as exercise/sport.
