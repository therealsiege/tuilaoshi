# 设 To Set Up

- **Character**: 设
- **Pinyin**: shè
- **Meaning**: to set up, to establish, to install
- **Radical**: 讠 (speech)
- **Stroke count**: 6

## Compounds

- 设计 (shè jì) — to design
- 建设 (jiàn shè) — construction

## Example Sentences

- 他设计了这栋房子。(Tā shè jì le zhè dòng fáng zi.) — He designed this house.

## Notes

设 means to set up or establish. Essential in设计 (design) and建设 (construction).
