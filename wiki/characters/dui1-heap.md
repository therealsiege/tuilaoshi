# 堆 Heap, pile

- **Character**: 堆
- **Pinyin**: duī
- **Meaning**: heap, pile
- **Radical**: 土 (earth)
- **Stroke count**: 11

## Compounds

- 堆栈 (duī zhàn) — stack
- 堆内存 (duī nèi cún) — heap memory

## Example Sentences

- 堆内存用于动态分配。(Duī nèi cún yòng yú dòng tài fēn pèi.) — Heap memory is used for dynamic allocation.

## Notes

Memory management term, used in 堆 (heap), 堆栈 (stack)
