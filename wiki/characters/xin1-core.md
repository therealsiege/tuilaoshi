# 芯 Core

- **Character**: 芯
- **Pinyin**: xīn
- **Meaning**: core, chip, wick
- **Radical**: 艹 (grass)
- **Stroke count**: 7

## Compounds

- 芯片 (xīn piàn) — chip, microchip
- 核芯 (hé xīn) — core

## Example Sentences

- 这个芯片是国产的。(Zhè ge xīn piàn shì guó chǎn de.) — This chip is domestically produced.

## Notes

芯 with grass radical originally meant wick, now essential for semiconductor terminology.
