# 跑 Run

- **Character**: 跑
- **Pinyin**: pǎo
- **Meaning**: to run
- **Radical**: 足 (foot)
- **Stroke count**: 12

## Compounds

- 跑步 (pǎo bù) — to run, running
- 长跑 (cháng pǎo) — long-distance running

## Example Sentences

- 他每天早上跑步五公里。(Tā měi tiān zǎoshang pǎobù wǔ gōnglǐ.) — He runs five kilometers every morning.

## Notes

Basic running verb; used in all running and track contexts
