# 页 Page

- **Character**: 页
- **Pinyin**: yè
- **Meaning**: page, leaf
- **Radical**: 页 (page)
- **Stroke count**: 6

## Compounds

- 网页 (wǎng yè) — web page
- 页面 (yè miàn) — page

## Example Sentences

- 打开这个网页。(Dǎ kāi zhè ge wǎng yè.) — Open this web page.

## Notes

页 originally meant head, now standard radical and character for page/leaf.
