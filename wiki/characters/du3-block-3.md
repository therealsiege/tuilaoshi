# 堵 Block, clog

- **Character**: 堵
- **Pinyin**: dǔ
- **Meaning**: block, clog
- **Radical**: 土 (earth)
- **Stroke count**: 11

## Compounds

- 堵塞 (dǔ sè) — block, clog
- 阻塞 (zǔ sè) — block

## Example Sentences

- 网络被堵塞了。(Wǎng luò bèi dǔ sè le.) — The network is congested.

## Notes

Used in 堵塞 (congestion), 拥堵 (traffic jam), network issues
