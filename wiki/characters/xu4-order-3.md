# 序 Order, sequence

- **Character**: 序
- **Pinyin**: xù
- **Meaning**: order, sequence
- **Radical**: 广 (shelter)
- **Stroke count**: 7

## Compounds

- 程序 (chéng xù) — program
- 顺序 (shùn xù) — sequence, order

## Example Sentences

- 请按顺序排列这些数据。(Qǐng àn shùn xù pái liè zhè xiē shù jù.) — Please arrange this data in order.

## Notes

Used in 程序 (program), 顺序 (sequence), fundamental to algorithms and data structures
