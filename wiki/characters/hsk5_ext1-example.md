# 例 Example, Case, 例如 For Example

- **Character**: 例
- **Pinyin**: lì
- **Meaning**: example, case, 例如 for example
- **Radical**: 亻(person)
- **Stroke count**: 8

## Compounds

- 例如 (lì rú) — for example
- 例子 (lì zi) — example
- 病例 (bìng lì) — medical case

## Example Sentences

- 有很多水果，例如苹果、香蕉等。(Yǒu hěn duō shuǐguǒ, lìrú píngguǒ, xiāngjiāo děng.) — There are many fruits, for example apples, bananas, etc.

## Notes

Essential for giving examples in academic and formal writing. 例如 (for example) is extremely common.
