# 数 Number, data

- **Character**: 数
- **Pinyin**: shù
- **Meaning**: number, data
- **Radical**: 攵 (tap)
- **Stroke count**: 13

## Compounds

- 参数 (cān shù) — parameter
- 数据 (shù jù) — data

## Example Sentences

- 数据很重要。(Shù jù hěn zhòng yào.) — Data is important.

## Notes

Essential for 数据 (data), 参数 (parameter), 函数 (function)
