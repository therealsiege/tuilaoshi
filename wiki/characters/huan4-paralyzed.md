# 痪 Paralyzed

- **Character**: 痪
- **Pinyin**: huàn
- **Meaning**: paralyzed
- **Radical**: 疒 (sickness)
- **Stroke count**: 12

## Compounds

- 瘫痪 (tān huàn) — paralyzed, down
- 麻痹 (má bì) — paralyzed

## Example Sentences

- 服务器瘫痪了一小时。(Fú wù qì tān huàn le yī xiǎo shí.) — The server was down for an hour.

## Notes

Used in 瘫痪 (paralyzed/down), system failure terminology
