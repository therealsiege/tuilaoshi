# 崩 Crash, collapse

- **Character**: 崩
- **Pinyin**: bēng
- **Meaning**: crash, collapse
- **Radical**: 山 (mountain)
- **Stroke count**: 11

## Compounds

- 崩溃 (bēng kuì) — crash, collapse
- 崩盘 (bēng pán) — crash (system)

## Example Sentences

- 程序崩溃了。(Chéng xù bēng kuì le.) — The program crashed.

## Notes

Used in 崩溃 (crash), system failure terminology
