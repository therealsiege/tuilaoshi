# 值 Value

- **Character**: 值
- **Pinyin**: zhí
- **Meaning**: value, worth
- **Radical**: 亻(person)
- **Stroke count**: 10

## Compounds

- 价值 (jià zhí) — value
- 数值 (shù zhí) — numerical value

## Example Sentences

- 这个参数值不对。(Zhè ge cān shù zhí bú duì.) — This parameter value is wrong.

## Notes

值 is essential for all value-related terminology in programming and mathematics.
