# 案 Case

- **Character**: 案
- **Pinyin**: àn
- **Meaning**: case, legal case, file
- **Radical**: 木 (wood)
- **Stroke count**: 10

## Compounds

- 案件 (àn jiàn) — case
- 档案 (dàng àn) — file

## Example Sentences

- 警察正在调查这个案件。(Jǐng chá zhèng zài diào chá zhè ge àn jiàn.) — The police are investigating this case.

## Notes

案 wood 木 table with offerings 安, place where cases are examined.
