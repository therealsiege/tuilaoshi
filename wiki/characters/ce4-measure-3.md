# 测 Measure, test

- **Character**: 测
- **Pinyin**: cè
- **Meaning**: measure, test
- **Radical**: 氵 (water)
- **Stroke count**: 9

## Compounds

- 测试 (cè shì) — test
- 检测 (jiǎn cè) — detect, test

## Example Sentences

- 请检测系统是否正常。(Qǐng jiǎn cè xì tǒng shì fǒu zhèng cháng.) — Please test if the system is working properly.

## Notes

Essential for 测试 (test), 检测 (detect), 观测 (observe)
