# 搜 Search

- **Character**: 搜
- **Pinyin**: sōu
- **Meaning**: search
- **Radical**: 扌 (hand)
- **Stroke count**: 12

## Compounds

- 搜索 (sōu suǒ) — search
- 搜寻 (sōu xún) — search for

## Example Sentences

- 使用搜索引擎查找资料。(Shǐ yòng sōu suǒ yǐn qíng chá zhǎo zī liào.) — Use a search engine to find information.

## Notes

Used in 搜索 (search), 搜索引擎 (search engine), web search
