# 班 Class

- **Character**: 班
- **Pinyin**: bān
- **Meaning**: class, shift, team
- **Radical**: 王 (king/jade)
- **Stroke count**: 10

## Compounds

- 上班 (shàng bān) — go to work
- 班级 (bān jí) — class (school)

## Example Sentences

- 我们班有三十个人。(Wǒ men bān yǒu sān shí ge rén.) — Our class has thirty people.

## Notes

班 means class or work shift. 加班 = work overtime.
