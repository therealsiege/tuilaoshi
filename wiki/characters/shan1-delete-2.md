# 删 Delete, remove

- **Character**: 删
- **Pinyin**: shān
- **Meaning**: delete, remove
- **Radical**: 刂 (knife)
- **Stroke count**: 7

## Compounds

- 删除 (shān chú) — delete
- 删改 (shān gǎi) — delete and modify

## Example Sentences

- 你可以删除这个文件。(Nǐ kě yǐ shān chú zhè gè wén jiàn.) — You can delete this file.

## Notes

Essential operation, used in 删除 (delete), common in file and data management
