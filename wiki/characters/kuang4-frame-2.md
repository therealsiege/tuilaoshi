# 框 Frame

- **Character**: 框
- **Pinyin**: kuàng
- **Meaning**: frame, box
- **Radical**: 木 (tree)
- **Stroke count**: 10

## Compounds

- 框架 (kuàng jià) — framework
- 边框 (biān kuàng) — border, frame

## Example Sentences

- 这个框架很稳定。(Zhè ge kuàng jià hěn wěn dìng.) — This framework is very stable.

## Notes

框 with wood radical suggests wooden frames, now used for software frameworks and UI boxes.
