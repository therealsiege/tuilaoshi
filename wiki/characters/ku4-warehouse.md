# 库 Warehouse

- **Character**: 库
- **Pinyin**: kù
- **Meaning**: warehouse, repository
- **Radical**: 广 (shelter)
- **Stroke count**: 7

## Compounds

- 数据库 (shù jù kù) — database
- 仓库 (cāng kù) — warehouse

## Example Sentences

- 数据库需要备份。(Shù jù kù xū yào bèi fèn.) — The database needs to be backed up.

## Notes

库 with shelter radical for warehouse naturally extends to data repositories and libraries.
