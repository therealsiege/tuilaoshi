# 码 Code, number

- **Character**: 码
- **Pinyin**: mǎ
- **Meaning**: code, number
- **Radical**: 石 (stone)
- **Stroke count**: 8

## Compounds

- 代码 (dài mǎ) — code, source code
- 编码 (biān mǎ) — encoding, code

## Example Sentences

- 这段代码有一个错误。(Zhè duàn dài mǎ yǒu yī gè cuò wù.) — This code has an error.

## Notes

Essential for programming and computing, used in 代码 (code), 编码 (encoding), 密码 (password)
