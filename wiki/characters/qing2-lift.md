# 擎 Lift, engine

- **Character**: 擎
- **Pinyin**: qíng
- **Meaning**: lift, engine
- **Radical**: 手 (hand)
- **Stroke count**: 16

## Compounds

- 引擎 (yǐn qíng) — engine
- 发动机 (fā dòng jī) — engine

## Example Sentences

- 浏览器引擎需要更新。(Liú lǎn qì yǐn qíng xū yào gēng xīn.) — The browser engine needs updating.

## Notes

Used in 引擎 (engine), 渲染引擎 (rendering engine), software engines
