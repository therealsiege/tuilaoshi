# 滤 Filter

- **Character**: 滤
- **Pinyin**: lǜ
- **Meaning**: filter
- **Radical**: 氵 (water)
- **Stroke count**: 13

## Compounds

- 过滤 (guò lǜ) — filter
- 滤波 (lǜ bō) — filter (signal)

## Example Sentences

- 需要过滤噪音。(Xū yào guò lǜ zào yīn.) — Need to filter the noise.

## Notes

Used in 过滤 (filter), 滤波器 (filter), signal processing
