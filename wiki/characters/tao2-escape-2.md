# 逃 To escape, flee, run away

- **Character**: 逃
- **Pinyin**: táo
- **Meaning**: to escape, flee, run away
- **Radical**: 辶 (walk)
- **Stroke count**: 9

## Compounds

- 逃跑 (táo pǎo) — to run away, escape
- 逃避 (táo bì) — to escape, evade

## Example Sentences

- 小偷逃跑了。(Xiǎotōu táopǎo le.) — The thief ran away.

## Notes

Common character for escaping or fleeing.
