# 模 Model, pattern

- **Character**: 模
- **Pinyin**: mó
- **Meaning**: model, pattern
- **Radical**: 木 (wood)
- **Stroke count**: 14

## Compounds

- 模范 (mófàn) — model, exemplar
- 模式 (móshì) — mode, pattern

## Example Sentences

- 他是模范员工。(Tā shì mófàn yuángōng.) — He is a model employee.

## Notes

Common term for models, patterns, or exemplary examples.
