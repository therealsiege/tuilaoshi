# 值 Value

- **Character**: 值
- **Pinyin**: zhí
- **Meaning**: value, worth, to be worth
- **Radical**: 亻(person)
- **Stroke count**: 10

## Compounds

- 价值 (jià zhí) — value
- 值得 (zhí de) — to be worth

## Example Sentences

- 这本书很值得一读。(Zhè běn shū hěn zhí de yí dú.) — This book is worth reading.

## Notes

值 person 亻 plus 直 (straight), upright value.
