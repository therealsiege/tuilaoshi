# 退 Return, refund

- **Character**: 退
- **Pinyin**: tuì
- **Meaning**: return, refund
- **Radical**: 辶 (walk)
- **Stroke count**: 9

## Compounds

- 退货 (tuì huò) — return goods
- 退款 (tuì kuǎn) — refund

## Example Sentences

- 七天内可以无理由退货。(Qī tiān nèi kě yǐ wú lǐ yóu tuì huò.) — Can return goods without reason within seven days.

## Notes

退换 means return and exchange. 退税 means tax refund.
