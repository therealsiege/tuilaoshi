# 口 Port, interface

- **Character**: 口
- **Pinyin**: kǒu
- **Meaning**: port, interface
- **Radical**: 口 (mouth)
- **Stroke count**: 3

## Compounds

- 接口 (jiē kǒu) — interface, port
- 端口 (duān kǒu) — port

## Example Sentences

- USB接口在侧面。(USB jiē kǒu zài cè miàn.) — The USB port is on the side.

## Notes

Used in 接口 (interface), 端口 (port), 窗口 (window)
