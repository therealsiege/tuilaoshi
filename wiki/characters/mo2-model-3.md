# 模 Model, pattern

- **Character**: 模
- **Pinyin**: mó
- **Meaning**: model, pattern
- **Radical**: 木 (wood)
- **Stroke count**: 14

## Compounds

- 模型 (mó xíng) — model
- 模式 (mó shì) — pattern, mode

## Example Sentences

- 这是一个深度学习模型。(Zhè shì yī gè shēn dù xué xí mó xíng.) — This is a deep learning model.

Used in 模型 (model), 模式 (pattern), 建模 (modeling)
