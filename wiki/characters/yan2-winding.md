# 蜒 Winding, extending

- **Character**: 蜒
- **Pinyin**: yán
- **Meaning**: winding, extending
- **Radical**: 虫 (insect)
- **Stroke count**: 12

## Compounds

- 蜿蜒 (wān yán) — winding, meandering
- 延蜒 (yán yán) — extending

## Example Sentences

- 小路蜿蜒向前。(Xiǎo lù wān yán xiàng qián.) — The path winds forward.

## Notes

Usually paired with 蜿 to describe winding paths
