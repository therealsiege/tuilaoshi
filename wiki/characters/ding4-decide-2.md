# 定 Decide, fix, set

- **Character**: 定
- **Pinyin**: dìng
- **Meaning**: decide, fix, set
- **Radical**: 宀 (roof)
- **Stroke count**: 8

## Compounds

- 决定 (juédìng) — decide, decision
- 定罪 (dìngzuì) — convict, find guilty

## Example Sentences

- 法院定罪量刑。(Fǎyuàn dìngzuì liàngxíng.) — The court convicted and sentenced.

## Notes

Common for deciding, fixing, and setting.
