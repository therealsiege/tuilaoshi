# 始 Begin, start

- **Character**: 始
- **Pinyin**: shǐ
- **Meaning**: begin, start
- **Radical**: 女 (woman)
- **Stroke count**: 8

## Compounds

- 开始 (kāishǐ) — begin, start
- 始终 (shǐzhōng) — from beginning to end, always

## Example Sentences

- 会议即将开始。(Huìyì jíjiāng kāishǐ.) — The meeting is about to begin.

## Notes

Common formal character for beginnings.
