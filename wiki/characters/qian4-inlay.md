# 嵌 Inlay, embed

- **Character**: 嵌
- **Pinyin**: qiàn
- **Meaning**: inlay, embed
- **Radical**: 山 (mountain)
- **Stroke count**: 12

## Compounds

- 镶嵌 (xiāng qiàn) — inlay, set
- 嵌入 (qiàn rù) — embed, insert

## Example Sentences

- 戒指上镶嵌着一颗钻石。(Jiè zhi shàng xiāng qiàn zhe yī kē zuàn shí.) — A diamond is set in the ring.

## Notes

Used for inlaying precious stones or embedding objects.
