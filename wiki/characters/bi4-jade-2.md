# 璧 Jade Disk

- **Character**: 璧
- **Pinyin**: bì
- **Meaning**: jade disk with hole
- **Radical**: 玉 (jade)
- **Stroke count**: 18

## Compounds

- 璧玉 (bì yù) — precious jade
- 完璧归赵 (wán bì guī Zhào) — return jade intact to Zhao

## Example Sentences

- 这是一块完整的古代玉璧。(Zhè shì yí kuài wán zhěng de gǔ dài yù bì.) — This is an intact ancient jade disk.

## Notes

璧 has jade 玉 with 辟 phonetic, ceremonial jade disk.
