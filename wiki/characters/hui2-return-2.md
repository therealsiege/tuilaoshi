# 回 Return, recycle

- **Character**: 回
- **Pinyin**: huí
- **Meaning**: return, recycle
- **Radical**: 囗 (enclosure)
- **Stroke count**: 6

## Compounds

- 回收 (huí shōu) — recycle, recover
- 返回 (fǎn huí) — return

## Example Sentences

- 这些材料可以回收。(Zhè xiē cái liào kě yǐ huí shōu.) — These materials can be recycled.

## Notes

Used in 回收 (recycle), 返回 (return), 回路 (circuit)
