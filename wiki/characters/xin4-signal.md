# 信 Signal, message

- **Character**: 信
- **Pinyin**: xìn
- **Meaning**: signal, message
- **Radical**: 亻 (person)
- **Stroke count**: 9

## Compounds

- 信号 (xìn hào) — signal
- 信息 (xìn xī) — information

## Example Sentences

- 信号很弱。(Xìn hào hěn ruò.) — The signal is weak.

## Notes

Used in 信号 (signal), 信息 (information), 通信 (communication)
