# 线 Cable, line

- **Character**: 线
- **Pinyin**: xiàn
- **Meaning**: cable, line
- **Radical**: 纟 (silk)
- **Stroke count**: 8

## Compounds

- 网线 (wǎng xiàn) — network cable
- 连线 (lián xiàn) — wire, cable

## Example Sentences

- 请连接网线。(Qǐng lián jiē wǎng xiàn.) — Please connect the network cable.

## Notes

Used in 网线 (cable), 电线 (wire), 在线 (online), 线程 (thread)
