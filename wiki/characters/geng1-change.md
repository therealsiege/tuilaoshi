# 更 Change, update

- **Character**: 更
- **Pinyin**: gēng
- **Meaning**: change, update
- **Radical**: 曰 (say)
- **Stroke count**: 7

## Compounds

- 更新 (gēng xīn) — update
- 变更 (biàn gēng) — change

## Example Sentences

- 系统需要更新。(Xì tǒng xū yào gēng xīn.) — The system needs to be updated.

## Notes

Used in 更新 (update), 变更 (change), essential for software maintenance
