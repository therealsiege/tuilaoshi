# 码 Code

- **Character**: 码
- **Pinyin**: mǎ
- **Meaning**: code, number
- **Radical**: 石 (stone)
- **Stroke count**: 8

## Compounds

- 密码 (mì mǎ) — password
- 号码 (hào mǎ) — number

## Example Sentences

- 请输入您的密码。(Qǐng shū rù nín de mì mǎ.) — Please enter your password.

## Notes

码 is fundamental to digital technology terminology, combining with 编 for programming code.
