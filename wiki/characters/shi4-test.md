# 试 Test, try

- **Character**: 试
- **Pinyin**: shì
- **Meaning**: test, try
- **Radical**: 讠 (speech)
- **Stroke count**: 8

## Compounds

- 测试 (cè shì) — test
- 调试 (tiáo shì) — debug

## Example Sentences

- 我们需要测试这个功能。(Wǒ men xū yào cè shì zhè gè gōng néng.) — We need to test this function.

## Notes

Used in 测试 (test), 调试 (debug), 尝试 (try), essential for QA
