# 不 vs 没 Negation

- **Pattern**: 不 + Verb/Adjective (habitual/future) / 没(有) + Verb (past/completed)
- **Structure**: S + 不 + V/Adj / S + 没(有) + V

## Explanation

Chinese has two primary negation words, and the choice between them is not free — it depends on aspect and meaning.

不 (bù) negates habitual actions, future intentions, willingness, adjectives, and stative verbs. It says "this is generally not the case" or "I will not / do not."

没 (méi), often expanded to 没有 (méiyǒu), negates completed actions and past events. It says "this did not happen" or "has not yet occurred." 没 also negates the verb 有 (yǒu, to have): 我没有钱 (I don't have money). Note that 不有 is ungrammatical — 有 is always negated with 没.

**Tone sandhi**: 不 is fourth tone (bù) but changes to second tone (bú) before another fourth-tone syllable: 不是 (bú shì), 不去 (bú qù), 不对 (bú duì). This is covered in IC1 Lesson 4.

## Example Sentences

- 我不喝咖啡。(Wǒ bù hē kāfēi.) — I don't drink coffee. (habitual)
- 他明天不来。(Tā míngtiān bù lái.) — He's not coming tomorrow. (future)
- 今天不冷。(Jīntiān bù lěng.) — It's not cold today. (adjective)
- 我没去图书馆。(Wǒ méi qù túshūguǎn.) — I didn't go to the library. (completed)
- 她没有哥哥。(Tā méiyǒu gēge.) — She doesn't have an older brother. (有 negation)

## Negation

This page is itself about negation. The core rule summarized:

| Use 不 | Use 没 |
|--------|--------|
| Habitual actions | Completed actions |
| Future intentions | Past events |
| Adjectives | 有 (always) |
| Modal verbs (不想, 不能) | Actions not yet done |
| Willingness / preferences | Experience (没去过) |

## Common Errors

- Using 不 for completed actions: ✗ 我昨天不去。 ✓ 我昨天没去。(Wǒ zuótiān méi qù.) — I didn't go yesterday.
- Using 没 with adjectives: ✗ 今天没冷。 ✓ 今天不冷。(Jīntiān bù lěng.) — It's not cold today.
- Using 不 with 有: ✗ 我不有时间。 ✓ 我没有时间。(Wǒ méiyǒu shíjiān.) — I don't have time.
- Using 了 with 没: ✗ 我没去了。 ✓ 我没去。(Wǒ méi qù.) — I didn't go. (没 already implies non-completion, so 了 is contradictory.)
