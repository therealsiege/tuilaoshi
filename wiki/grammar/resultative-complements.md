# Resultative Complements 看见/听懂/学会/做完/找到

- **Pattern**: Verb + Result
- **Structure**: V + Result Complement / V + 得/不 + Result (potential form)

## Explanation

Resultative complements (结果补语, jiéguǒ bǔyǔ) are verb compounds where the second element describes the result or outcome of the action expressed by the first element. They answer "what happened as a result of doing V?" This is introduced in IC1 Lesson 16.

Common resultative complement pairings:

| Compound | Pinyin | Meaning |
|----------|--------|---------|
| 看见 | kàn jiàn | look + perceive = see |
| 听懂 | tīng dǒng | listen + understand = understand (by listening) |
| 看懂 | kàn dǒng | look + understand = understand (by reading) |
| 学会 | xué huì | study + master = learn successfully |
| 做完 | zuò wán | do + finish = finish doing |
| 找到 | zhǎo dào | search + arrive = find |
| 买到 | mǎi dào | buy + arrive = succeed in buying |
| 写错 | xiě cuò | write + wrong = write incorrectly |
| 听清楚 | tīng qīngchǔ | listen + clear = hear clearly |
| 吃饱 | chī bǎo | eat + full = eat until full |

**Potential form**: Insert 得 (affirmative: "can achieve the result") or 不 (negative: "cannot achieve the result") between the verb and the complement:
- 看得见 (kàn de jiàn) — can see
- 看不见 (kàn bú jiàn) — cannot see
- 听得懂 (tīng de dǒng) — can understand (by listening)
- 听不懂 (tīng bù dǒng) — cannot understand (by listening)

The potential form expresses ability or possibility based on circumstances, not permission or skill (which uses 能 or 会).

## Example Sentences

- 你看见那个人了吗？(Nǐ kàn jiàn nà ge rén le ma?) — Did you see that person?
- 老师说的话你听懂了吗？(Lǎoshī shuō de huà nǐ tīng dǒng le ma?) — Did you understand what the teacher said?
- 我学了很久，终于学会了。(Wǒ xué le hěn jiǔ, zhōngyú xué huì le.) — I studied for a long time and finally learned it.
- 作业做完了。(Zuòyè zuò wán le.) — The homework is finished.
- 字太小了，我看不清楚。(Zì tài xiǎo le, wǒ kàn bù qīngchǔ.) — The characters are too small; I can't see them clearly.

## Negation

For actions that did not achieve the result, use 没(有):
- 我没看见他。(Wǒ méi kàn jiàn tā.) — I didn't see him.
- 她没听懂。(Tā méi tīng dǒng.) — She didn't understand.

For inability to achieve the result, use the potential negative form (V + 不 + Result):
- 我看不见。(Wǒ kàn bú jiàn.) — I can't see (it).
- 这本书我看不懂。(Zhè běn shū wǒ kàn bù dǒng.) — I can't understand this book.

## Common Errors

- Using 不 instead of 没 for past non-achievement: ✗ 我不看见他。 ✓ 我没看见他。(Wǒ méi kàn jiàn tā.) — I didn't see him.
- Confusing potential form with degree complement: ✗ 他说得懂中文。(degree complement structure) ✓ 他说得好。(degree) / 他听得懂中文。(potential) — Different structures for "how well" vs "whether possible."
- Separating the compound with an object: ✗ 我看书见了。 ✓ 我看见那本书了。(Wǒ kàn jiàn nà běn shū le.) — The object follows the entire compound.
